# inginx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Single-binary Rust OpenAI-compatible inference proxy with API-key GUI, exact usage metering, full-fidelity request logging, and OTel GenAI export.

**Architecture:** One axum/tokio process. Proxy core on `/v1/*` (auth → model resolution → streaming forward with tee), SQLite (WAL, rusqlite) with a dedicated log-writer task, and a maud+htmx admin GUI under `/admin` with argon2 password + WebAuthn 2FA.

**Tech Stack:** axum 0.8, tokio, reqwest (stream feature), rusqlite (bundled), maud, webauthn-rs, argon2, zstd, tokenizers, ulid, serde_json, anyhow, tower-http.

**Spec:** `docs/superpowers/specs/2026-09-02-inginx-design.md`

## Global Constraints

- Rust edition 2021; no Node/npm anywhere; frontend assets are vendored static files under `assets/` embedded with `include_bytes!`/`include_str!`.
- One SQLite DB file, WAL mode, `foreign_keys=ON`. All schema changes via `db::migrate`.
- Client-facing errors always use OpenAI's error JSON shape: `{"error":{"message":...,"type":...,"code":...}}`.
- API keys: format `igx_` + 40 base62 chars; only SHA-256 hex stored; first 8 chars of the random part stored as `key_prefix`.
- Every request record stores `usage_source` as `"upstream"` or `"estimated"`.
- Payload blobs zstd-compressed (level 3) before insert.
- Commit after every task with a conventional-commit message ending in the session trailer:
  `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01SMT1uvd4LEQdUrWYSwh5JM`.
- Run `cargo test` before every commit; all tests must pass.

```rust
use anyhow::Result;
use rusqlite::Connection;
use std::{path::Path, sync::{Arc, Mutex}};

#[derive(Clone)]
pub struct Db(Arc<Mutex<Connection>>);

pub fn now() -> i64 { time::OffsetDateTime::now_utc().unix_timestamp() }

const SCHEMA: &str = r#"
CREATE TABLE IF NOT EXISTS backends (
  id INTEGER PRIMARY KEY, name TEXT NOT NULL UNIQUE, base_url TEXT NOT NULL,
  upstream_api_key TEXT, enabled INTEGER NOT NULL DEFAULT 1, is_default INTEGER NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS models (
  id INTEGER PRIMARY KEY, backend_id INTEGER NOT NULL REFERENCES backends(id) ON DELETE CASCADE,
  upstream_name TEXT NOT NULL, alias TEXT NOT NULL UNIQUE, enabled INTEGER NOT NULL DEFAULT 1);
CREATE TABLE IF NOT EXISTS api_keys (
  id INTEGER PRIMARY KEY, name TEXT NOT NULL, key_hash TEXT NOT NULL UNIQUE, key_prefix TEXT NOT NULL,
  all_models INTEGER NOT NULL DEFAULT 0, created_at INTEGER NOT NULL,
  revoked_at INTEGER, expires_at INTEGER);
CREATE TABLE IF NOT EXISTS key_models (
  key_id INTEGER NOT NULL REFERENCES api_keys(id) ON DELETE CASCADE,
  model_id INTEGER NOT NULL REFERENCES models(id) ON DELETE CASCADE,
  PRIMARY KEY (key_id, model_id));
CREATE TABLE IF NOT EXISTS requests (
  id TEXT PRIMARY KEY, ts INTEGER NOT NULL, key_id INTEGER, model TEXT, endpoint TEXT NOT NULL,
  status INTEGER NOT NULL, latency_ms INTEGER NOT NULL, ttfb_ms INTEGER,
  prompt_tokens INTEGER NOT NULL DEFAULT 0, completion_tokens INTEGER NOT NULL DEFAULT 0,
  usage_source TEXT NOT NULL, error TEXT, req_headers TEXT, resp_headers TEXT,
  req_body BLOB, resp_body BLOB);
CREATE INDEX IF NOT EXISTS idx_requests_ts ON requests(ts);
CREATE INDEX IF NOT EXISTS idx_requests_key ON requests(key_id, ts);
CREATE TABLE IF NOT EXISTS usage_hourly (
  key_id INTEGER NOT NULL, model TEXT NOT NULL, hour INTEGER NOT NULL,
  n_requests INTEGER NOT NULL DEFAULT 0, prompt_tokens INTEGER NOT NULL DEFAULT 0,
  completion_tokens INTEGER NOT NULL DEFAULT 0, n_errors INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (key_id, model, hour));
CREATE TABLE IF NOT EXISTS admin_credentials (
  id INTEGER PRIMARY KEY CHECK (id = 1), username TEXT NOT NULL, password_hash TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS webauthn_credentials (
  id INTEGER PRIMARY KEY, cred_json TEXT NOT NULL, created_at INTEGER NOT NULL);
CREATE TABLE IF NOT EXISTS sessions (
  token TEXT PRIMARY KEY, created_at INTEGER NOT NULL, expires_at INTEGER NOT NULL);
CREATE TABLE IF NOT EXISTS settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
"#;

impl Db {
    pub fn open(path: &Path) -> Result<Db> {
        let conn = Connection::open(path)?;
        conn.pragma_update(None, "journal_mode", "WAL")?;
        conn.pragma_update(None, "foreign_keys", "ON")?;
        conn.execute_batch(SCHEMA)?;
        Ok(Db(Arc::new(Mutex::new(conn))))
    }

    pub async fn call<T, F>(&self, f: F) -> Result<T>
    where T: Send + 'static, F: FnOnce(&mut Connection) -> Result<T> + Send + 'static {
        let db = self.0.clone();
        tokio::task::spawn_blocking(move || {
            let mut conn = db.lock().unwrap();
            f(&mut conn)
        }).await?
    }
}
```

### Task 7: Log store — writer task, rollup, retention

**Files:**
- Create: `src/logstore.rs`
- Modify: `src/main.rs` (`mod logstore;`)

**Interfaces:**
- Consumes: `db::Db`, `metering::Usage`.
- Produces:
  - `logstore::LogRecord { id: String /*ULID*/, ts: i64, key_id: Option<i64>, model: Option<String>, endpoint: String, status: u16, latency_ms: u32, ttfb_ms: Option<u32>, usage: Usage, usage_source: &'static str, error: Option<String>, req_headers: String, resp_headers: String, req_body: Vec<u8>, resp_body: Vec<u8> }` (bodies raw; compression happens in the writer)
  - `logstore::LogWriter` (clone) with `fn send(&self, rec: LogRecord)` (non-blocking; drops+warns if the bounded channel of 1024 is full)
  - `logstore::spawn_writer(db: Db) -> LogWriter` — task inserts record + upserts `usage_hourly` in one transaction; zstd-compresses bodies
  - `logstore::prune(db, max_age_secs: Option<i64>, max_db_bytes: Option<i64>) -> Result<u64>` — deletes by age, then oldest-first until DB size (page_count*page_size) fits; returns rows deleted
  - `logstore::spawn_pruner(db: Db)` — hourly loop reading `settings` keys `retention_max_age_secs` / `retention_max_db_bytes`
  - `logstore::get_bodies(db, id: &str) -> Result<Option<(Vec<u8>, Vec<u8>)>>` — decompressed

Handler logic (single fallback handler for any method under `/v1/`):
1. Extract bearer from `Authorization`; `authenticate` → else 401 `openai_error(..., "invalid_api_key")`.

3. `prepare_upstream_body` → forward: method, path+query appended to `base_url`, headers forwarded only `content-type`/`accept`, plus `Authorization: Bearer <upstream_api_key>` if the backend has one.
4. Await full response (this task: non-streaming only — if upstream replies with `text/event-stream`, still pass through unbuffered but without usage-chunk filtering; Task 9 replaces this).
5. Extract usage (`extract_usage_json`, fallback `estimate_body_tokens` on request body → `usage_source="estimated"`), build `LogRecord`, `log.send`.
6. `GET /v1/models`: authenticated; returns `{"object":"list","data":[{"id":alias,"object":"model","owned_by":"inginx"}]}` from `models_for_key`.
